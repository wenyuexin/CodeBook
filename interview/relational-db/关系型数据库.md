# 关系型数据库

### 一、基本问题

 1. **什么是关系型数据库？请简述其核心特征。**

    - 基于关系模型（表、行、列）组织数据；支持 SQL 查询；保证 ACID 特性；提供数据完整性和约束（主键、外键、唯一、检查等）。

 2. **解释 ACID 四个特性的含义及作用。**

    - 原子性（Atomicity）：事务中的所有操作要么全部成功，要么全部失败。

    - 一致性（Consistency）：事务前后数据库的完整性约束未被破坏。

    - 隔离性（Isolation）：并发事务互不干扰。

    - 持久性（Durability）：事务提交后数据永久保存。

 3. **事务隔离级别有哪些？分别解决什么问题？**

    - READ UNCOMMITTED（读未提交）→ 脏读

    - READ COMMITTED（读已提交）→ 不可重复读

    - REPEATABLE READ（可重复读）→ 幻读（部分数据库可解决）

    - SERIALIZABLE（串行化）→ 全部问题

 4. **什么是索引？有哪些常见类型？索引的优缺点？**

    - 类型：B-Tree、Hash、全文索引、位图索引等。

    - 优点：加速查询；缺点：占用空间、降低 DML 性能。

 5. **主键、唯一索引、普通索引的区别？**

    - 主键：唯一且非空，一个表只能一个。

    - 唯一索引：允许一个 NULL（部分数据库允许多个 NULL），可多个。

    - 普通索引：仅加速查询。

 6. **什么是范式？简述 1NF、2NF、3NF。**

    - 1NF：列不可再分。

    - 2NF：满足 1NF 且非主属性完全依赖主键（消除部分依赖）。

    - 3NF：满足 2NF 且非主属性不传递依赖主键。

 7. **什么是视图？视图与表的区别？**

    - 视图是虚拟表，存储查询逻辑，不直接存数据。可简化查询、控制权限。

 8. **什么是存储过程？与函数的区别？**

    - 存储过程是一组预编译 SQL，可包含流程控制；函数必须有返回值且不能有副作用。

 9. **什么是触发器的使用场景？**

    - 自动执行日志记录、数据校验、级联更新等。

10. **如何优化一条慢 SQL？**

    - 分析执行计划、检查索引、避免隐式转换、减少返回列、改写子查询为 JOIN、分页优化等。

### 二、系型数据库对比

MySQL vs PostgreSQL vs Oracle vs SQL Server

|特性|MySQL|PostgreSQL|Oracle|SQL Server|
|-|-|-|-|-|
|**开源/商业**|开源（GPL）|开源（PostgreSQL License）|商业|商业|
|**默认隔离级别**|REPEATABLE READ（InnoDB）|READ COMMITTED|READ COMMITTED|READ COMMITTED|
|**并发控制**|MVCC（InnoDB）|MVCC（更成熟）|MVCC + Undo|MVCC + 锁|
|**JSON 支持**|较好（5.7+）|极佳（原生 JSON 类型）|一般|较好|
|**全文搜索**|支持（中文需插件）|支持（更强大）|支持（Oracle Text）|支持（Full-Text）|
|**分区表**|支持（范围、列表等）|支持（声明式分区）|支持（丰富）|支持|
|**复制与高可用**|主从、组复制、MGR|流复制、逻辑复制、BDR|Data Guard、RAC|Always On|
|**扩展性**|垂直扩展为主|水平扩展较灵活|强大（RAC、Sharding）|良好|
|**学习曲线**|低|中等|高|中等|
|**典型应用场景**|Web、OLTP、LAMP|复杂分析、地理空间、HTAP|金融、大型企业|.NET 生态、企业级|
